# 四足

輪式的問題之所以乾淨,靠三個前提:支撐面固定、平面運動、接觸不切換。四足把這三個**同時**打掉——不是難一點,是換了一類問題。

- **[足式的根本分岔:基座浮起來了](legged-fundamentals.md)** — 為什麼找不到任何一顆馬達連到軀幹(欠致動)、接觸集合有 16 種讓系統變成混合系統、支撐多邊形一路退化到消失、ZMP 與 capture point 各保證什麼、沒有輪子時狀態怎麼估(以及水平位置與 yaw 為什麼在數學上不可觀測)。
- **[步態與致動](gait-and-actuation.md)** — duty factor 的門檻由相位怎麼排決定(不是固定的 0.5)、腳每步撞地一次讓工業手臂那套減速機不能用、QDD 與 SEA 是「衝擊被誰吸收」的兩種答案、為什麼強化學習在這裡主導,以及安全標準目前是空的。

## 兩件跟其他形態不同的事

**控制方法的重心不一樣。** 輪式與移動操作的難題大半可以寫成方程式解掉;四足的接觸切換寫不出封閉解,所以強化學習不是「另一種選擇」,是主流路線。這也讓 [sim-to-real](../../50-physical-ai/sim-to-real.md) 那一章從「進階選讀」變成必讀。

**法規是空的。** ISO 3691-4 明訂不適用於具主動控制穩定性的機器人、ISO 10218 不管移動、ISO 13482 限非工業場域——四足掉在三者中間。制定中的 ISO/CD 25785-1 就是為了補這個洞,但截至查證時仍是草案。細節見[步態與致動 §6](gait-and-actuation.md#6-安全標準這一塊目前是空的)。
