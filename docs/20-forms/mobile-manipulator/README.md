# 移動操作:搬運車 + 機械手臂

底盤那一半的問題,本筆記已經解得差不多了([輪式 AMR](../wheeled-amr/) 與[共通核心](../../10-core/));手臂那一半有整套成熟的工業方法。真正的難題在**兩者相加才長出來的東西**——自由度加起來變成冗餘、底盤定位精度比抓取需求差一個數量級、伸臂會改變重心讓車有翻的風險。

- **[手臂運動學](arm-kinematics.md)** — 為什麼 FK 一定有解而 IK 不一定、DH 參數為什麼恰好 4 個、六軸手臂為什麼典型有 8 組解、球型手腕是機構遷就求解的結果、Jacobian 的三重身分(速度 / 力 / 可操作度)。
- **[移動操作:底盤與手臂的耦合](mobile-manipulation.md)** — 冗餘與零空間投影、三種協調策略、誤差預算怎麼分配、傾覆判準,以及 MoveIt 2 生態與安全標準各自缺的那一塊。

## 為什麼這兩篇要分開

手臂運動學那些現象(多解、奇異點、Jacobian 對偶)在**手臂固定在地上**時就全部存在,跟底盤無關;把它們跟「底盤也會動」混在一起講,會分不清哪些問題是手臂本來就有的、哪些是裝上車才有的。先講清楚固定手臂,再把底盤接回來,分岔點才看得出來。
